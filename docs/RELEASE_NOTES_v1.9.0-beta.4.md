# FocuBili v1.9.0 Beta 4

预览构建号 `2029`。本轮主要解决从搜视频、打开播放工具到回看时间点笔记时遇到的问题。

<!-- focubili-update-summary:start -->
- 搜索结果的更多菜单更容易点中。离线修改本地筛选时，已加载的结果仍可用。
- 播放器把字幕、列表、循环和听视频放到菜单前面。长按松手后能恢复原倍速，短区间在高倍速下也能继续循环。
- 字幕刷新或重试保留搜索词，窄屏放大字号并打开键盘时仍可操作重试。
- 复习笔记时可直接看正文节录和命中片段；导出只包含仍可见的选中项。
- 已购课堂切换账号后不会显示旧列表；订阅失败可以按来源重试，不会把已读条目再当成新通知。

## 搜索、播放与复习

- 搜索结果的「更多」点击区域扩大到 48 × 48 dp，图标不变。播放器菜单优先显示听视频、字幕、列表和循环，屏蔽与黑名单放在末尾。笔记列表突出标题、正文节录、视频时间点和来源；按正文搜索时展示命中片段。改筛选后，隐藏的选中项不会被导出；补封面也不会恢复已删笔记或覆盖新写的正文。[#112](https://github.com/L1Xu4n/FocuBili/pull/112)
- 搜索断网时可在已加载的结果中修改或清空本地关键词筛选。切换远端分区或加载下一页仍可能需要联网。读取失败时不覆盖本地规则，取消屏蔽失败时保留原状态。[#106](https://github.com/L1Xu4n/FocuBili/pull/106)
- 长按加速松手后恢复原倍速；A–B 标记条挪到视频下方，短区间在高倍速下也能回跳；自动切集不再盖掉手动上一项。macOS 取消静音时恢复上次非零的应用音量。[#107](https://github.com/L1Xu4n/FocuBili/pull/107)
- 字幕同轨刷新或重试保留搜索词。短屏、大字号、键盘打开时可以滚动到重试按钮。它不会生成字幕，也不改变自动选轨规则。[#108](https://github.com/L1Xu4n/FocuBili/pull/108)
- 播放线路设置可点整行查看优先顺序，下次加载生效。Windows 先按原有顺序回退；原有方案都失败后，再有上限地尝试不同序号的音视频备线。未保证特定网络的连接速度。[#104](https://github.com/L1Xu4n/FocuBili/pull/104)

## 课堂、订阅与学习

- 已购课堂在链接弹窗跨前后台后仍会刷新，切号后清除旧列表，购买列表跨页重复时继续读取。观看仍需当前账号持有 B 站权限。[#103](https://github.com/L1Xu4n/FocuBili/pull/103)
- 订阅可只重试失败来源并继续未完成的分页，同时抑制已读条目的重复通知。手机后台调度仍由系统决定。[#105](https://github.com/L1Xu4n/FocuBili/pull/105)
- 本机专注历史未成功读取前不写入新数据。添加整合集时可选分 P 和分组，取消不写入；在分组内继续学习不会跨组。[#109](https://github.com/L1Xu4n/FocuBili/pull/109)

## 安装和验证范围

- Android 预览包名仍为 `com.focubili.app.preview`，与正式版并存。使用沿用官方签名的 APK，可覆盖更新官方 **v1.9.0 Beta 3（2028）**。不能覆盖早期使用其他签名的预览包，例如 **v1.8.0 Beta 4（2024）**，也不会自动迁移正式版资料。若系统提示签名不一致，先备份资料，不要卸载旧包来强行安装。
- Windows 候选提供 x64 安装器和便携 ZIP，Linux DEB 的主要支持目标是 Ubuntu 24.04 amd64。macOS DMG 使用 ad-hoc 签名，未公证；iOS IPA 未签名，不是可直接安装的 TestFlight 版本。
- [旧 issue 对照与验收记录](v1.9/legacy-issue-followup.md) 汇总代码、控件和原生 CI 证据。[#110](https://github.com/L1Xu4n/FocuBili/pull/110) 补充验收记录，[#111](https://github.com/L1Xu4n/FocuBili/pull/111) 放宽 Linux CI 总时限，未改变依赖或验收标准。
- 本轮交互回归以 Flutter 控件、合成接口和 CI 为主；没有把 ColorOS 桌面、原校园网、真实已购账号、外接音响或系统文件选择器列为已复验。
