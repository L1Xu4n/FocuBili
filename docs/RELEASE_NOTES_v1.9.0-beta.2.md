# FocuBili v1.9.0 Beta 2

这是 GitHub Pre-release 测试版，构建号 `2027`。正式版仍为 v1.8.1。

<!-- focubili-update-summary:start -->
- 播放列表支持分 P、合集、B 站与本机收藏夹、学习清单连续播放，并可选择播完暂停、顺序播放、单项循环或列表循环。
- 首页抽屉可以关闭；新增可自行添加的“我的收藏”“我的关注”卡片，可选择具体内容并排序。
- 新增按账号隔离的本机关注分组，支持预览导入 B 站分组、编辑成员及排序。
- A–B 标记支持收起后保留草稿，使用紧凑操作条；字幕可调整垂直位置。
- 整合默认播放线路、避开 PCDN 偏好、完整备用音视频组合优先回退，以及笔记按分 P 和时间排序。
- macOS 增加应用音量与静音；补齐 Android 夜间自适应图标，Linux 安装包沿用实际 ELF 依赖分析。

## 主要改动

- **#81 播放列表**：从收藏或学习清单进入时保持原来源及其排序，在线列表按需分页并提供失败重试。普通视频先播放分 P；学习清单严格播放已保存的分 P。列表仅在本次会话使用，不自动加入相关推荐。
- **#89 首页与关注**：首页右上角保留“自定义首页”，关闭抽屉或隐藏全部卡片后仍可找回。新卡片默认隐藏，添加后可在入口与自选内容之间切换。关注分组只保存在本机，按账号 UID 隔离；导入读取 B 站已有分组，不创建或修改远端分组。重复导入保留本机名称、顺序与移除记录。分组及卡片配置可随资料导出。
- **#74 A–B**：标记 A 后可收起面板、继续播放或拖动，再标记 B；切换视频或分 P 会清除草稿。时间输入按需展开。
- **#88 线路**：提供智能、主线优先、备用优先和优先避开 PCDN；保持原始签名 URL 与编码兼容顺序。
- **#80 macOS 音量**：音量滑块控制播放器的软件音量，不依赖外接显示器的系统音量能力。
- **#87 图标**：为 Android 26/33 及以上补齐夜间自适应图标资源，避免夜间 PNG 抢先匹配后被桌面再次套框。
- **#82 Linux**：DEB 根据打包的 ELF 实际依赖生成声明，不再固定写入未经链接依据确认的 libjsoncpp25。
- 保留 Beta 1 的课堂、同步读写边界、导出、手势与布局能力（#50、#56、#58、#60、#61、#62），并整合 #90 笔记排序与 Apple 暂停视频浮窗取帧修正。

## 安装与待测试项

- Android 使用独立包名 `com.focubili.app.preview`，可与正式版共存，不自动迁移正式版资料。签名与安装身份由发布流水线校验。
- Windows 提供 x64 安装器和便携 ZIP；Linux DEB 面向 Ubuntu 24.04 amd64，Ubuntu 26.04 的实际安装仍需目标环境复测，不扩大到 22.04。
- macOS DMG 使用 ad-hoc 签名，未做 Apple 公证；iOS IPA 未签名，需要自行签名安装，不属于 TestFlight 分发。
- ColorOS 15 深色桌面图标、Mac 外接音响和校园网线路效果仍需原设备／网络复测。自动回归与模拟器操作不替代这些验收。
- B 站分组导入依赖当前登录会话与接口可用性；读取失败不会提交半份分组。配置只在本机保存，资料导出不等同于完整备份恢复。
- 本轮未加入 #78、#79、评论区、字幕生成或 AI 语义搜索。

## 建议体验

1. 从多 P、收藏夹或学习清单进入播放器，试用上一项／下一项和四种播放模式，确认定时停止与 A–B 优先。
2. 收起并重新打开 A–B 设置，调整字幕位置；在横竖屏观察控制栏避让。
3. 关闭首页抽屉，再从自定义入口恢复；添加收藏、关注卡片，选择内容后重启检查。
4. 导入一次关注分组，改名或移除成员后重复导入，检查本机修改保留；切换账号检查隔离。

本版本只发布为 Pre-release，不合并 master，不改变正式版 latest。
