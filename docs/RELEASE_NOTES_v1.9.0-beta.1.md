这次测试版围绕学习资料整理、连续专注和字幕阅读展开。

## 版本与安装身份

本测试版的版本标识为 `1.9.0-beta.1`，共享构建计数为 **2026**。Beta 仅作为预发布提供，不改变正式 1.8 的 latest 定位。安装包身份、构建来源和校验数据请按该 tag 的 CI 与 `beta-release-manifest.json` 核对。

Android Beta 采用独立包名 `com.focubili.app.preview`，与正式版 `com.focubili.app` 分开，不自动迁移正式版资料。受控 Beta release 使用既有 CI 证书，SHA-256 为 `65EF1FB301FB1121C1803E752F5B1EB24E55846502D8B5478F0FC11F58E9A8A9`。本测试版不要求与归档 Beta 证书一致；APK 的有效签名、递增版本、ABI、BuildTime/source 和文件哈希仍需按实包及该 tag 证据核对。

归档 Beta3、Beta4、Beta5 的构建计数分别为 2023、2024、2025，使用另一证书 `5bd1fc4daa8a0887e213c4dc1231d0eba4f7f309a0e64c2d15fe404302bd00b0`。新计数 2026 不能消除证书差异，因此新包不能覆盖这些旧 Beta；旧 Beta 覆盖升级不属于本 Beta 的发布必需项。请保留原应用及其数据，不卸载、清数据或替换签名来试包；可在空白的专用测试环境中试用。若另测覆盖升级，只使用已确认安装身份匹配且构建号递增的测试环境。

Windows、macOS、Linux 和 iOS 沿用稳定版的应用/安装身份与资料路径，不提供独立 Beta 数据沙箱。学科清单升级后不能交给旧版写回同一份资料。macOS 打包目标为 ad-hoc 签名、未公证；iOS 产物为 unsigned，需要另行签名与 provisioning，不能描述为可直接安装或已经通过 TestFlight 发布。实际包状态仍以对应 CI 和实包证据为准。

## 连续专注与学习清单

专注从点击开始后独立计时。暂停视频、切换视频或分 P、回首页和搜索均保持同一次会话；点击“专注暂停”或应用进入后台才暂停累计，返回前台后由用户继续。计划到时或主动结束后归档一次。旧历史保留，旧活动任务迁移为暂停状态。

学习清单增加一层学科文件夹，可以新建、重命名、筛选和移动视频。删除文件夹时，其内容回到未分组，视频、学习进度及关联记录保留。

## 笔记与字幕

一条时间点笔记可以追加多张视频画面，每张保留自己的时间。可调整顺序、删除画面、查看长图；Markdown 与 JSON 导出包含截图及时间点，旧单图笔记兼容。截图缺失会明确提示，保留文字和缺图位置。

播放器可查看 B站已提供的字幕，搜索文本并点击跳转；可导出 SRT 或带起止时间的文本。没有可读取字幕时会说明原因，不生成不存在的字幕。

笔记导出的取消和失败提示更加明确，失败显示脱敏诊断码。Issue #61 仍缺准确平台、版本和复现步骤，本版没有把它认定为已复现的 Mac 问题，也不宣称已解决未知原因。

## A–B 区间循环

从播放器“更多选项 → A–B 区间循环”进入，用当前播放点标记 A/B，或输入时间，反复看、听同一片段。时间轴显示区间，视频和听视频模式共用；暂停保留区间，清除后恢复原来的普通播放或整片循环设置。

区间只属于当前视频和分 P，切换内容、退出播放页或主动跳到区间外时清除。最短区间为一秒。实际回跳精度取决于媒体和平台，后台、锁屏及耳机控制仍需真机核对。

## 黑名单与搜索

可以在搜索视频菜单和播放器菜单屏蔽视频或 UP，从“我的”或搜索筛选进入黑名单管理并取消。UP 按账号 UID 匹配，避免同名误伤。标题与 UP 关键词分别排除，分区筛选默认不限制，旧设置保留。用户主动保存的清单、收藏、笔记和历史不会因此删除。

## 已购课堂

增加“我的 → 已购课程”，识别官方课堂 ss/ep 链接，支持课程章节、进度和时间点笔记。只处理当前账号已购买且仍有权限的课程，不绕过付费限制。

课程播放仍需要有已购内容的账号在 Android 和桌面实际测试。DRM、多段媒体拼接、课堂独立字幕/弹幕暂不支持，遇到这些情况请使用官方课堂。付费课程不接入离线下载和跨账号可复用的磁盘媒体缓存。

## 首页与统一导出

首页抽屉提供关闭、半开、全开三个位置，快速手势最多跨一档；从深层卡片返回时先停在展开边界，减少误关闭。

设置 → 账号与隐私 → 统一导出，可以选择笔记与截图、清单和专注、本地收藏、历史与可读取进度、订阅、已载入字幕、离线目录及设置。资料包保存在本机，不包含登录凭据、Cookie 或 Token。字幕仅覆盖本次运行仍有效的已载入内容，视频媒体继续从原离线视频入口单独导出。

Android 勾选历史时还会附带本机已保存的逐 P 播放进度。导出读取已提交的文件快照，不改写播放记录，不包含尚未落盘的位置，也不保证各服务处于完全同一时刻。

## Beta 更新通道

新 1.9 的更新器可检查后续 Beta 预发布，稳定通道继续检查正式版。Android 只有在当前 preview 包身份完整、证书指纹与候选一致、构建号合法且候选严格更高时才提供 APK 直链；身份缺失、非法或不匹配时打开对应 Release 页面。该入口只决定下载选择，不替代实包验签、系统安装校验或资料保留验收。

旧 Beta3/4/5 自带的更新器不会被这次代码追溯修复，也不承诺它们能够自动更新或覆盖升级到新 Beta。

学科清单使用新版存储结构，升级后请勿用旧版 App 写回同一份资料。统一导出便于保存和阅读，暂不提供完整回滚恢复。

自动化测试和合成界面截图不代表真机验收，45 项人工测试均待做。构建来源与包校验请查看该 tag 的 CI、`beta-release-manifest.json` 和校验表；具体检查结果及待人工测试项见 `docs/v1.9/`。升级和测试请保留已有学习资料，不要为解决签名不一致而直接卸载旧应用。
