## 首页抽屉与自选卡片（#50、#89）

- 首页上滑时，搜索区与卡片同向移动，不再反向下沉或逐帧模糊。快速上滑可一次到首张卡片；下滑可一次关闭。慢拖至中点可半开，深层列表的惯性回滑不会误关抽屉。
- 本机收藏夹和关注分组改名后，首页及时显示新名。已确认账号、但远端列表不可用时仍可配置本机内容；无法确认账号时先提示重试，不会误读或改写游客设置。

## 学习笔记（#97）

- 在正文输入 Markdown 后，点「Markdown 预览」查看排版。旧笔记仍可直接编辑，原有时间点和视频截图保留，仍可导出为 Markdown 或 JSON。
- 长按已有截图或点保存按钮，将截图原图存到所选位置。另存后仍可在笔记中查看原图。

- 窄屏放大文字时，宽表格可横滑阅读到末列。无法读取的截图不会被保存或误报成功。

## 字幕（#97、#98）

- 在播放器打开「字幕 → 外观」，可以预览并调整位置、字号和不透明度；文字和底色会同时变化。
- 「默认开启字幕」初始关闭。打开后，普通在线视频会按设置选择可用字幕，优先轨道不可用时尝试其他轨道。仍可在播放器手动切换字幕或关闭当前视频的字幕。
- 自动选择适用于有 B 站字幕轨道的普通在线视频。B 站「课堂」和本地视频继续沿用各自既有的播放能力。

## 安装说明

- Android 预览版包名为 `com.focubili.app.preview`，可与正式版并存。已有预览可覆盖安装，正式版资料需自行备份或迁移。
- Windows 提供 x64 安装器和便携 ZIP。Linux 提供 amd64 DEB。macOS DMG 使用 ad-hoc 签名，iOS IPA 需自行签名安装。
