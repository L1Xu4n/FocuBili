## 主要更新

1. **焦点订阅**：新版首页提供一次性选择。开启后添加首页卡片与快捷按钮，并进入订阅设置；拒绝后不启用、不添加卡片，之后仍可从“我的”开启。已经开启订阅的 Beta 用户保留原有选择和布局。
2. **消息与来源管理**：略微增大封面，点击卡片即可播放；移除“收到日期”“未读”和独立播放按钮。长按消息或来源进入多选，支持全选、批量标已读、加入学习清单、暂停和删除。点击 UP/合集页面的订阅按钮，也可确认取消。
3. **更清楚的消息列表**：按发现日期从新到旧分组；已读消息单独放在底部，七天后清除展示记录。来源头像和合集缩略图可筛选消息，筛选区域随上滑收起、下滑展开。清理已读记录不会删除学习资料或清空去重记录。
4. **播放器反馈与布局**：倍速状态留在顶部，音量/亮度与短消息各自布局；提示独立淡出并移动收拢。修复双击快进快退反馈及取消侧滑后的收尾；侧滑和双击暂停不再额外呼出播放栏。长按倍速可在设置中自定义。
5. **大屏与学习体验**：平板首次启动完成协议后说明横屏布局，可选择改用竖屏；设置中也可切换，重启生效。首页和“我的”卡片在间隙拖动、反向移动及保存时更稳定；笔记截图按原比例预览，进度条展示实际缓冲范围。
6. **数据与诊断**：设置提供登录和偏好的独立导入导出，重置偏好保留账号和学习资料。登录文件是敏感明文 Cookie，必须由用户确认保存，导入经 B 站验证后才切换会话。关于页显示构建号、BuildTime，问题诊断增加运行环境与设备公开状态，继续过滤账号、Cookie、地址和用户内容。

## 订阅检查的边界

- UP 主建立有限基线；合集自动检查只读取默认及反向首两页，避免扫描大量旧视频。合集任意中间位置新增或重排可能不在这部分范围内；需要完整历史时使用单独的历史导入。
- Android 使用既有 WorkManager。开启每小时检查时，建议将省电设为无限制、在多任务加锁并开启自启动；系统和厂商仍可能延迟任务，不能保证整点送达。
- Windows、Linux、macOS 使用应用进程内原生计时器，失焦/最小化时可检查；退出、休眠、挂起后不保证。iOS 使用系统机会式后台刷新，不保证每小时；系统不允许时仍可在前台检查。Apple/Linux原生构建和真实设备后台机会仍待对应CI/设备验收。
- 订阅保存在当前设备，不会修改 B 站账号关注，也不提供云端同步。

## 安装与验证

正式安装包及精确构建提交将在审查、CI与下载验证后登记。Android 沿用历史正式包名与发布证书；请保留旧版数据，不要为更新先卸载。Beta 预览包与正式版包名不同，数据不会自动跨包迁移。

Windows 安装器、macOS DMG、Linux DEB 随同提交构建验证后发布。macOS 现有签名与公证能力、iOS 未签名构建的分发限制将如实记录；不把测试渲染或编译通过当作真实设备实播验收。
