# FocuBili v1.8.0 发布说明

版本号：`1.8.0+26` · Windows 包版本：`1.8.0.26`

这次更新的重点是焦点订阅。把想跟进的 UP 主和合集加进来，在首页查看更新，再把感兴趣的视频放进学习清单。订阅和系统通知都由你选择是否开启。

- 新增焦点订阅，在本机跟进 UP 主和合集更新，可选首页卡片与系统通知。
- 订阅消息点击即可播放，支持长按多选、全选、批量标已读和加入学习清单。

- 优化播放器双击反馈、提示避让与侧滑操作，支持自定义长按倍速。
- 进度条显示实际缓冲范围，笔记图片按原比例预览，全屏设置预览退出后恢复布局方向。

- 合入 1.7.1 的 Android 播放会话、画质选择修复及「忽略本次更新」。

## 焦点订阅

- 首页提供一次性开启提示。同意后开启订阅、置顶订阅卡片，并提供快捷入口；拒绝则保留原布局，之后仍可手动开启。「我的」默认将订阅入口放在设置上方。
- 消息卡略微放大封面，去掉卡片上的收到日期、未读标签和独立播放按钮，点击卡片即可播放。
- 长按消息可进入多选，支持全选、批量标记已读和加入学习清单。来源也支持多选、批量暂停和删除；点击来源可打开对应 UP 主或合集页，页面上的订阅按钮支持取消订阅。
- 消息按发现日期从新到旧分组，未读优先，已读集中在底部并显示分隔。已读满七天后清理消息列表中的记录，保留去重记录和学习资料。
- 使用 UP 主头像、合集缩略图筛选消息；筛选条随滚动收起和展开，给消息列表留出更多空间。
- 系统通知显示视频标题和来源副标题。关闭通知、暂停或删除来源后，旧请求不再继续提醒；专注期间抑制订阅通知。

## 播放器与界面

- 完善双击快进、后退和播放暂停的反馈动画。侧滑和双击暂停保持播放栏原有的显示或隐藏状态；顶部状态、中央手势提示和字幕分区避让，短提示独立淡出收起。
- 长按倍速可以单独设置，松手后恢复原来的播放速度。双击触发区与播放栏大小继续提供全屏预览，退出预览后恢复 Android/iOS 的布局方向。
- 播放进度条显示播放器实际报告的已缓冲范围。
- 改善首页和「我的」卡片拖动，支持在卡片间隙插入，减少松手保存时的顺序闪回。
- 移动端可选择自动、横屏或竖屏布局，重启后生效；平板首次使用会在协议说明后展示布局选择。
- 竖屏下查看笔记截图时按图片原比例展示。

## 设置、诊断与修复

- 新增登录信息与设置的独立导入导出。设置文件只迁移偏好，保留账号、订阅源、笔记、学习清单和历史记录；导入后重启应用生效。
- 恢复默认设置会关闭订阅、通知和后台检查，保留登录状态、订阅源、学习资料及离线文件。登录导入经 B 站验证成功后才切换会话；导出的登录文件包含明文 Cookie，请妥善保存，不要分享。
- 点击首页标题可进入关于页；更新项目介绍，版本号包含构建号，关于页与诊断页显示 BuildTime。诊断页补充运行环境和播放后端信息，详细内容可折叠查看，不包含账号、Cookie 或媒体地址。
- 合入 1.7.1 的 Android 播放会话与画质选择修复，以及针对单个版本的「忽略本次更新」。

## 后台检查与使用说明

- Android 启用后台检查后请求每小时检查一次，实际执行时间由系统调度。省电、网络和厂商策略都可能延迟任务；可按页面提示调整省电、后台加锁与自启动选项，强制停止后需重新打开应用。
- Windows、Linux、macOS 在应用进程运行时可继续检查，包括失焦或最小化时；退出应用后不运行，休眠、挂起或离线时也不保证检查。
- iOS 使用系统机会式后台刷新，不保证每小时执行；系统不允许后台刷新时仍可在前台检查。
- 合集自动检查只读取默认顺序与反向顺序各前两页，避免反复扫描大型合集。中间位置任意新增或重排不保证覆盖，需要历史内容时可主动导入。
- 焦点订阅保存在当前设备，不改变 B 站账号的关注关系，暂不提供跨设备同步。系统通知是可选提醒，未收到通知时仍可在订阅页查看已发现的更新。

## 安装与升级

- Android 正式版使用 `com.focubili.app`，版本 `1.8.0`、构建号 `26`，沿用既有正式发布签名。现有正式版可直接覆盖升级，无需先卸载或清除数据。
- 旧 Beta 使用独立包名和签名，与正式版分开安装，不能直接覆盖，数据也不会自动迁移。请先备份重要资料。
- Windows 使用安装器升级；Linux DEB 面向 Ubuntu 24.04 amd64 / x86-64，其他发行版、旧版 Ubuntu 和 ARM 不在本次支持范围内。
- macOS DMG 内的应用采用 ad-hoc 签名，尚未经过 Apple 公证，系统可能限制首次打开。更新前先退出旧版，再替换应用。
- iOS 产物是未签名归档，需自行签名后才能安装，不是可直接安装的普通 IPA，也不是 App Store 或 TestFlight 分发。Apple 真机上的登录、长时间后台运行和跨签名身份升级尚未验收。
