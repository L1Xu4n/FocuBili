# 1.8.0-beta.1 实现与验证

学习清单使用共享添加面板，按 BV+CID 去重。所有读改写在同一 SharedPreferences 实例的共享队列串行进行；容量在队列内复核，拒绝整批超限。迁移保留 v1 备份，写入后 reload 验证，失败不覆写为空。学习页增加状态筛选与批量管理，失效 CID 要重新选择，专注关联规则保持原有行为。

订阅服务为应用级 ChangeNotifier，独立版本化 JSON 存储，保存上份有效快照与损坏隔离副本。UP 使用现有公开内容服务 latest 分页；UGC 扫全量 BV 快照。首次完整扫描只建基线；部分扫描的候选和页游标可持久化，只有完整扫描推进成功时间。每源 seen、全局永久 BV 索引与通知认领独立于 500 项展示缓存。单刷新锁、两个源并发、前台定时器和 epoch/source token 防止取消后过期结果写入。通知开关与权限独立且默认关闭，仅主动开启请求权限；先保存条目与认领，再发摘要。没有后台服务或云端推送。

## 接口复核

`api-verification.json` 为 2026-10-04 匿名实网复核的结构化结果。`tool/subscription_api_probe.dart` 使用当前 `BilibiliHttpPublicContentService` 和真实 HttpClient，可用 `flutter test tool/subscription_api_probe.dart` 单独复核，不进入日常离线测试套件。

- UP 公开 card 返回真实名称；nav 未登录 -101 仍提供 WBI 签名资源。
- 签名 arc/search 返回 -352，兼容回退 arc/search 返回 HTTP 412。当前环境不能通过匿名 UP 视频流风控；没有假定 Cookie 一定解除风控，登录实测待完成。
- owner mid 517327498 / season 3993361：第一页 20，第二页 2，总数 22。发布时间不单调，验证了合集不能按最新页或发布时间判断新增。
- 合集及 UP 基于现有会话/签名/分页实现复用；没有采用 issue 中建议的 ajax 接口，也没有把 20 当作接口限制。
