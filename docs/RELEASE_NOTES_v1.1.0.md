# FocuBili v1.1.0 发布说明

发布日期：2026 年 8 月 3 日

Android 最低版本：Android 7.0（API 24）

应用版本：`1.1.0+9`

## 本次重点

v1.1.0 完成了按视频分P管理的学习清单、可跨进程和重启恢复的 Android 专注提醒、统一权限管理、提醒诊断，以及时间点截图查看器重写。

### 学习清单

- 同一视频的不同分P可以分别加入学习清单，加入和完成状态互不影响。
- 支持按视频、UP 主或分P搜索，并允许用户调整未完成任务的顺序。
- 已完成分P自动移动到列表末尾，与未完成任务分隔。
- “继续学习”只按清单顺序打开下一个未完成分P，不会重新播放已完成任务。
- 只有学习清单中的当前分P真实完播后才显示完成提示。
- 完播提示提供“标记已完成”和“继续学习”；最后一个任务完成后明确显示“已完成学习”。
- 首页在每次重新进入时读取最新清单状态，加入或取消后的任务可以立即显示。
- 播放器、搜索页和学习清单中的加入/取消反馈统一显示在页面底部。

### 专注提醒与 Android 权限

- 专注提醒改由 Android `AlarmManager` 安排，不依赖 Flutter 页面或应用进程持续存活。
- 待提醒任务保存在应用私有存储；设备重启、应用升级或重新取得精确闹钟权限后，会重新安排尚未触发的任务。
- 每次设置提醒都会重新检查通知权限和“闹钟和提醒”特殊访问权限。
- 小米、Redmi 和 POCO 设备首次成功设置提醒后，会说明后台自启动和无限制电量设置的重要性。
- “我的 → 设置 → 权限管理”集中展示通知、精确闹钟、勿扰、电量限制和厂商后台自启动的状态、用途、申请及管理/取消入口。
- 原有功能内的权限入口继续保留，用户从系统设置返回后统一权限页会自动刷新。
- 自动勿扰恢复为视频播放时开启、用户暂停时恢复；快进快退造成的短暂缓冲不会反复开关勿扰。

### 问题诊断

- 问题诊断新增待触发提醒数量、精确闹钟权限、通知状态、后台限制和最近安排/触发时间。
- 保存最近的安排、取消、重启恢复和通知触发结果，方便区分“闹钟未安排”“系统未唤醒”和“通知被权限拦截”。
- 清空诊断记录不会取消仍在等待的真实提醒。
- 复制内容不包含 Cookie、登录凭据、搜索内容、笔记正文、专注目标、提醒原因、会话编号或完整请求地址。

### 播放器与时间点笔记

- 修复“继续学习”切换下一条任务时播放器卡住的问题。
- 修复已完成学习任务进入播放器后被改回“学习中”的问题。
- 修复同一视频某一分P加入后，其他分P错误显示为已加入的问题。
- 播放器笔记面板恢复为约占屏幕三分之二，不再强制铺满整个画面。
- 非全屏打开笔记后进入全屏，会继续保持当前笔记本状态。
- 优化全屏笔记分P标签和截图布局。
- 时间点截图查看器改用专用图片缩放组件：初始完整居中，支持双击、双指缩放、拖动和一键回正。

### 图标与启动体验

- 修复部分真机安装后显示 Android 默认机器人图标的问题。
- 重新生成普通和圆形启动图标，并调整自适应图标安全区，避免模拟器桌面显示过大或过小。
- 更新 Android 12 及以上启动主题和旧系统启动背景，减少只显示主题色或默认占位图的问题。

## 已知限制

- 项目依赖非官方公开接口，接口可能随平台策略调整而变化。
- 厂商后台自启动没有统一的 Android 查询接口，小米/HyperOS 用户仍需在系统页面手动确认已经开启。
- 不同品牌对划掉多任务、待机和省电模式的处理不同，后台提醒仍需在更多真机持续验证。
- 在系统设置中强行停止应用属于更严格的停止状态，不作为普通“划掉后台”提醒场景。
- Release APK 使用项目当前的本机签名配置；长期公开分发前仍应迁移到独立并妥善保管的正式签名密钥。
