## 账号互动

- 播放器详情页接入点赞、投币、收藏和关注/取消关注的真实功能。
- 点赞、投币和收藏按钮显示 B 站公开数量，成功操作后同步更新本地显示。
- 投币支持选择投 1 枚或 2 枚硬币，并按当前账号已投数量限制可选项。
- 收藏支持多选收藏夹、同时添加或取消收藏，也支持创建新收藏夹。
- 合作视频的每位作者都显示独立的关注状态和关注按钮。
- 个性设置新增“账号只读”，默认开启；开启后不会执行点赞、投币、收藏、关注和其他账号写入操作。

## 视频与播放

- 合作视频详情支持多位作者展示。
- 视频标题和简介支持选中、复制；简介中的链接和 @UP 点击行为保持可用。
- 优化简介链接识别，中文正文紧邻链接时不会吞掉后续文字；视频区域正常显示的 BV/AV 元数据不作为简介异常处理。
- 播放多分P视频时，全屏播放栏显示当前分P标题。
- 分段进度条在普通进度条出现时保持相同的视觉长度。
- Windows 播放器全屏时隐藏鼠标，修复窗口化全屏与播放器全屏之间的冲突。
- Windows 首页专注功能恢复显示时间点截图。
- Windows 首次播放遇到画面已有但音频未就绪时，更快切换备用线路。

## 记录与设置

- 搜索设置新增“启用搜索记录”开关，默认开启。
- 观看设置新增“启用观看记录”开关，默认开启。
- 关闭记录开关后不再写入新的对应记录，已有记录仍可查看和删除。
- Android 支持检测剪切板中的 B 站链接，并可在设置中启用或关闭跳转询问。
- 个性设置改为多级页面，按账号隐私、播放专注和外观应用分类。

## 搜索与清单

- 修复 Windows 鼠标点击搜索候选词时，输入框先失焦导致候选点击无反应的问题。
- UP 主主页的学习清单入口改为图标状态，已加入时显示勾选图标，再次点击可以取消。
- 合集分P条目使用学习清单图标替代播放图标，支持直接加入或取消。
