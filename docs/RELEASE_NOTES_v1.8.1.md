# FocuBili v1.8.1 发布说明

版本号：`1.8.1+31` · Windows 文件版本：`1.8.1.31`

<!-- focubili-update-summary:start -->
- 修复了串字幕、字幕不可用的问题。
- 字幕现在不再与分段进度条重叠。
- 设置支持调整界面文字大小，最高 200%。
- 小的 UI 改进。

## 字幕与界面

- 字幕请求、正文缓存及重试绑定当前视频、分 P 和字幕文档，切换视频时撤销旧结果；字幕元数据请求适配当前接口。
- 字幕根据分段条的实际高度避让，适配横竖屏、全屏、安全区及不同字幕字号。
- 在「设置 → 外观与应用 → 界面文字大小」调整界面文字，范围为 80%–200%，与系统字号叠加。字幕继续使用播放器内的独立字号设置。
- 自动字幕按接口信息显示 AI 标签；字幕设置提供仅含标识和哈希的来源诊断，便于排查。

## 安装与兼容

- Android 正式包使用 `com.focubili.app`，版本 `1.8.1`、构建号 `31`，沿用既有正式版签名。可覆盖升级正式版；预览版与 Beta 使用独立包名，不会自动迁移数据。
- Windows 提供 x64 安装包和便携包；Linux DEB 面向 Ubuntu 24.04 amd64 / x86-64。
- macOS DMG 包含通用架构应用，使用 ad-hoc 签名，未做 Apple 公证，系统可能拦截首次打开。
- iOS 提供未签名 IPA，需要自行签名才能安装，不是 App Store 或 TestFlight 分发。

多平台构建与自动回归不能替代真实设备验证；如仍遇字幕异常，可在字幕设置复制来源诊断反馈。
