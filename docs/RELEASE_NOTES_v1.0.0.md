# FocuBili v1.0.0

发布日期：2026-07-19

FocuBili v1.0.0 是首个完整覆盖专注计时、视频关联、统计看板、时间点笔记和播放器稳定性改进的正式版本。

## 主要功能

- 专注计时支持快捷时长、自定义时长、暂停/继续、提前结束、打断原因、提醒时间和通知权限引导。
- 视频播放页可自动关联当前视频和分P；关联视频播放时专注计时才继续累计。
- 首页 Pin 显示关联视频最后看到的画面、播放位置和退出原因，可直接返回视频。
- 完成专注时播放用户提供的完成音效，并显示覆盖全屏的礼花雨，可延长 5 分钟。
- 专注统计看板支持 7 天、30 天和全部范围，提供自适应折线图、Y 轴刻度、打断次数、完成情况和分享图。
- 专注记录支持搜索、状态筛选、排序、删除、清空和点击返回关联视频。
- 时间点笔记支持截图、搜索、批量多选、Markdown/JSON/ZIP 导出与系统分享。
- 笔记详情支持生成包含标题、正文、BV、视频标题、分P、时间点、字数和截图的自适应长图。
- 视频简介中的 `@UP` 可点击跳转，HTTP(S) 链接会先展示风险提示，再使用系统默认浏览器打开。
- UP 主页补充认证资料，长简介支持展开/收起。
- 新增“关于”页面，展示版本、项目地址、项目负责人和 GitHub Release 状态。
- 可配置启动更新检查；发现新版本时在“我的”和“关于”入口显示红点并提供 Release 跳转。
- 首次安装展示第三方项目用户须知与使用协议，并提供一次性登录引导。

## 播放器与兼容性

- 播放器按功能拆分合集、布局、控制栏、弹幕和全屏状态组件。
- Media3 升级到 1.10.1，并优先选择 AVC/H.264 视频轨道，降低部分视频的底层解析失败。
- 支持多P上一集/下一集、选集对齐、全屏锁定、横竖屏切换和播放位置恢复。
- 修复专注记录跳转显示 00:00 但实际从头播放、完成记录无法跳转等问题。
