以下截图使用实际 `PlayerPage` 和同一组合成课程/普通视频数据，不含真实视频画面、账户、UP 主资料。旧版基于 `8245c6b`。

进入任意视频或课堂，点播放画面右上角的 **⋮**。面板打开时视频可继续播放；返回键、Escape、关闭按钮或点外侧只关面板。课堂不提供“屏蔽该视频”；作者信息缺失时会注明为什么不能屏蔽该 UP 主。

截图用 Flutter 测试宿主捕获，不代表各平台的原生播放器实机验收。
