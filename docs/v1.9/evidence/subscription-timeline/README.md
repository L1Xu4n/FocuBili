# 焦点订阅：来源栏和时间收件箱

来源可在顶部横向滑动（支持鼠标拖动）。仅从当前可见的更新决定是否提示：未打开过的更新来源靠前，再按最近收到时间排列。首次点该来源即确认当时的可见更新，不改变视频已读；切回全部来源不确认任何来源。下次该来源收到新内容会再亮；同一视频属于两个来源时分别确认。

减少动画或启用无障碍导航时，仅保留静态提示和「有新更新」朗读，不播放呼吸动画。已打开状态按账号和订阅实例在本机保存，不同步至 B 站或系统通知。屏蔽及已经从更新列表清理的内容不触发提示。来源改名、视频标已读都不产生新更新。

列表以收到日期分组，保留已读分隔、仅未读、今日发布和批量操作。点行播放；每行更多菜单可查看发布日期、标已读或加入学习清单；长按选择多项。实际封面从原有图片缓存加载。
