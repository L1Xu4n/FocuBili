# 首页抽屉：找回正式版的背景下坠

首页上拉时，欢迎区（标题、搜索与个人入口）按 [v1.8.1 的实现](https://github.com/L1Xu4n/FocuBili/blob/dd3ebb7de85fa02120b74debf8fd85d525a573da/lib/features/focus/focus_dashboard_home_layout.dart#L82-L112) 下坠、变模糊并淡出；卡片始终保持清晰，按手指移动。不回滚 [#100 的滚动、吸附与深列表修复](https://github.com/L1Xu4n/FocuBili/pull/100)。

欢迎区在自己的裁剪区域内绘制，不能覆盖卡片。关闭或完全离开视口时没有启用高斯滤镜。在编辑、抽屉已关闭、首屏过高、系统减少动态效果或辅助导航时，保留自然滚动和清晰的搜索控件。例如 320 × 500 dp、200% 字体时，新版欢迎区高 472 dp，高于 436 dp 的安全界线，故只自然滚动；旧版在该尺寸的欢迎区恰为 436 dp，当时仍有模糊。横向工作台没有上拉抽屉，布局不变。

对照使用同一套真实 Flutter 首页、中文字体和合成的本机设置：正式 v1.8.1、beta.4 与修复版。静态对照按相同滚动距离取帧；动图另以模拟指针的实际按住、移动和松手驱动，不对画面插值。测试还检查 59 个滚动采样不会重新构建或绘制静态欢迎子树。此处不代表实体手机、系统读屏或 GPU 帧率实测。

独立检查还从 390 dp 宽的实际渲染帧量了按钮边缘：上拉 140 dp 后，搜索按钮上沿 10%–90% 颜色过渡带从 0.8 px 加宽到约 9.25 px，同样区间内前景与背景的颜色距离从 262.4 降到 147.6；正式版同一帧得到相同数值，beta.4 的边缘仍为 0.8 px。系统运行中开关「减少动态效果」时，已用 Tab 聚焦的搜索按钮保持原焦点，Enter 仍可打开搜索。

动图来自手机尺寸下 81 次实际指针与吸附采样（位移 0 → 768 → 0 dp），编码时合并完全相同的重复画面。用来对照效果的修复版截图基于本次独立的 dev 分支；#127 定义的编辑入口和 #132 的收藏/关注配置在另外的组合树中验证，截图不表示回滚这些后续改动。
