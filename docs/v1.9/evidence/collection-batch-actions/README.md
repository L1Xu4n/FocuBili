## 复核路径

1. 普通点击仍播放。从某行长按或使用“选择视频”进入多选，普通点按只改变选中，不读取播放详情。
2. 按住某个勾选框，拖过条目；回拖则缩回本轮选区，保留先前独立勾选。滑到视口边缘可连续滚选；追加分页按 BV 去重，不把未加载视频计入所选。若某一整页都是重复 BV 但声明还有后页，会继续读取而不误判末页；连续三页都重合或页码停滞时改为显式“继续加载后续视频”。
3. “添加到”先明确选择学习清单或收藏夹。返回不写入且保留勾选；完成后才退出多选。学习支持分 P、分组与容量检查，本机收藏保留已有条目，不需要为每支视频联网。
4. B 站收藏须主动选择 B 站、目的夹并再次确认。只追加该夹，不移除其他夹。可停止后续、重试未完成项；每次写入核对账号和只读模式。线上覆盖使用模拟传输，不声称在真实账号执行过写入。

`test/collection_video_multiselect_test.dart` 用真实控件覆盖勾选、回拖、双列、去重、保存和取消；服务边界见 `test/bilibili_interaction_service_test.dart`。本改动依赖 #118 的共用拖选组件；两者合并前不要单独摘取页面文件。
