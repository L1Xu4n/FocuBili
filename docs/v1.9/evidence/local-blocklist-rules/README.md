# 本机黑名单：规则与验收

## 入口与匹配

从搜索「筛选 → 管理黑名单」、个人页或播放器更多菜单进入同一个黑名单。空列表中可以直接为 UP 主或视频添加规则：

| 类型 | 匹配 |
|---|---|
| UP 主 UID | 正整数精确匹配，改名不受影响。已有的 UID 屏蔽保留。 |
| 完整昵称 | 精确匹配完整昵称，同名账号也会命中。 |
| 昵称关键词 | 匹配包含该文字的昵称，不检查标题。 |
| 完整视频标签 | 精确匹配一条标签；不会匹配更长的标签、标题或昵称。 |
| 标题关键词 | 匹配包含该文字的视频标题，不检查标签或昵称。 |

文字规则忽略大小写与首尾空格，不使用正则表达式；同类型下重复规则不会再次保存。已有的 BV 屏蔽仍按稳定编号匹配，可单独解除。这里的规则不改写单独的搜索筛选设置，也不会发送到 B 站。

## 标签来源与边界

- 关键词视频搜索使用响应里已经有的 `data.result[].tag`。没有标签的卡片保留，规则不会为搜索列表每一条追加网络请求；已有的分 P 角标补查与本改动无关。
- 仅在用户主动点开某一条结果或搜索中直达 BV 时，如果仍缺标签且启用了标签规则，且没有其他确定命中，才请求这一条公开稿件的标签（`tag_name`）。已有标签直接匹配；先查到 BV 再新增规则，也会在点开结果时按当下规则复核，不会重新拉整页。标签取不到时不会仅因缺失而屏蔽，离线缓存和课堂不增加这个请求。
- 搜索覆盖视频结果、适用的用户结果和搜索中直达 BV。用户搜索命中 UID/昵称规则，不命中视频规则。新增的[投稿和焦点订阅显示范围](discovery.md)有独立的字段和本机数据边界。
- 对照过[哔哩哔哩公开视频页面上的标签区](https://www.bilibili.com/video/BV1T64y1D7qD/)。当前运行环境未能访问 JSON 端点，自动化把合成接口响应交给生产解析器和真实 Flutter 搜索控件。未在真实账号、实体设备或不同网络环境下验收。
