# 已购课程的本机缓存（候选）
本项与已购列表的封面、搜索无关。Beta 4 安装包没有课堂离线下载；以下指此草稿的 Android / Windows 实现，不是已发布承诺。

在支持的播放器中选中一章，点 **缓存本章**。在「我的 → 离线缓存」右上角打开 **课程缓存**，可暂停、继续、删除，或在本机授权仍有效时断网播放。暂停后继续需要重新联网校验；只有视音轨齐全时才会显示“离线播放”。课程缓存与普通视频下载及其导出入口分开。系统清理临时存储后需要重新缓存。

## 哪些课程不工作
- 必须能用当前账号在官方 API 验证登录 UID、有效购买、准确的季/章/稿件/CID、非试看、完整非保护流和期限。未知或不一致时不替换 ID、改接口或降级到游客。无有效期限、含水印保护、拒绝离线、DRM/证据不足，或不支持的清单、多段响应均拒绝。
- 仅支持可信 HTTPS CDN 明确返回的完整 DASH 音画或单段 MP4。文件到齐后再次检查 MP4 容器，发现保护标记、中断或缺失音画时不发布。不存在解密、取密钥、去水印、导出或跳过权限的路径。
- 按本机时间复核的连续使用窗口取 24 小时、购买有效期和可判定源有效期三者的最早值，可能明显少于一天。到期须重新联网缓存。退出或换号不能从本入口列出或播放原账号的文件；这不是设备文件加密、设备防篡改或 DRM。离线期间不可能即时知道上游刚撤销的资格，不承诺即时远端撤销。
- 不持久化购买清单、凭据或源地址。用户主动缓存的章节名称、标识、期限和字节数在该账号专属缓存目录保存；保留正常播放器已有的本机学习记录行为。Apple/Linux 此候选不开放入口。
- [哔哩哔哩付费内容购买协议](https://www.bilibili.com/blackboard/topic/activity-6yl-8aM9C.html) 对外部工具下载有约束，[官方版权保护说明](https://www.bilibili.com/opus/999131374433599491) 也说明部分课程受保护。获得播放响应**不等于**平台授予第三方离线许可。仅在课程提供方允许离线保存时使用，受保护或仅允许官方方式的课程请用官方产品。

## 已核／未核
真实 Flutter widget 流程覆盖缓存本章、管理列表、删除确认与取消、窄屏大字、切号期间旧内容消失。服务测试使用合成账号及授权响应，生产磁盘文件与回环 HTTP 检验续传；额外使用 FFmpeg 自建含画面及声音的 1 秒 MP4，在生产下载器下载、停止服务后，本机打开并实际解码音画。另验证真实单视频轨 MP4 不得标记为音画完整；Windows 播放后端校验账号、文件与章节一致，换号即停止。另有 Flutter → Android 本地播放参数测试和 Android JVM 路径、时限用例。
