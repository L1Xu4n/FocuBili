# 已购课程的本机缓存（候选）
本项与已购列表的封面、搜索无关。Beta 4 安装包没有课堂离线下载；以下指此草稿的 Android / Windows 实现，不是已发布承诺。

在支持的播放器中选中一章，点 **缓存本章**。在「我的 → 离线缓存」右上角打开 **课程缓存**，可暂停、继续、删除，或在本机授权仍有效时断网播放。暂停后继续需要重新联网校验；只有所需音画齐全，且未超过任何已知上游截止时才会显示“离线播放”。到期后选择「联网复核」；如果能证实本机媒体未变，不会再次下载整章。课程缓存与普通视频下载及其导出入口分开。系统清理临时存储后需要重新缓存。

## 哪些课程不工作
- 必须能用当前账号在官方 API 验证登录 UID、有效购买、准确的季/章/稿件/CID、非试看、完整非保护流。未知或不一致时不替换 ID、改接口或降级到游客。已知权限到期、含水印保护、明确禁止离线、DRM、无法验证购买或流身份，以及不支持的清单、多段响应均拒绝。明确已购买且数据完整时，单纯缺少期限字段不等同到期。
- 仅支持可信 HTTPS CDN 明确返回的完整 DASH 音画或单段 MP4。文件到齐后再次检查 MP4 容器，发现保护标记、中断或缺失音画时不发布。不存在解密、取密钥、去水印、导出或跳过权限的路径。
- 没有客户端自设的 24 小时或每日联网限制。上游返回明确的购买或离线截止时取最早值；只要上游没明确延长，后来缺失字段或传输失败都不会擦掉已知截止。没有已知截止时，同一账号的完整缓存可持续离线播放。临时 CDN 地址的时限只约束请求，不决定已验证本机文件的失效时间。到期不能继续离线播放；临时断网不能续期，也不会抹掉仍在有效期内的上一份凭据。明确失去权限或变为受保护媒体会撤销凭据。退出或换号不能从本入口列出或播放原账号的文件；这不是设备文件加密、设备防篡改或 DRM。离线期间不可能即时知道上游刚撤销的资格，不承诺即时远端撤销。
- 联网复核会重新确认同账号的购买资格、同季同章节（含稿件与 CID）、清晰度和完整非保护媒体。本机文件逐字节计算 SHA-256；仅当新源对同一可信资源、同一轨道返回相同的强 ETag 和完整长度时复用文件，不传输媒体正文。较大的本机文件仍需要时间校验。弱 ETag、缺少证明、内容或轨道改变、同样大小但字节损坏时不会续期旧文件；如仍有可用且允许的源，会重新下载。未记录版本的旧缓存可能需要重新下载一次；服务器始终不提供可靠版本证明时，每次均需重新下载。短时服务不可达且没有可用线路时，先提示重试，不默认为重新下载。
- 不持久化购买清单、账号凭据、源地址或原始 ETag。用户主动缓存的章节名称、标识、期限和字节数在该账号专属缓存目录保存；保留正常播放器已有的本机学习记录行为。Apple/Linux 此候选不开放入口。
- [哔哩哔哩付费内容购买协议](https://www.bilibili.com/blackboard/topic/activity-6yl-8aM9C.html) 对外部工具下载有约束，[官方版权保护说明](https://www.bilibili.com/opus/999131374433599491) 也说明部分课程受保护。获得播放响应**不等于**平台授予第三方离线许可。仅在课程提供方允许离线保存时使用，受保护或仅允许官方方式的课程请用官方产品。

## 已核／未核
[去掉 24 小时限制的回归报告](evidence/course-cache-server-limits/README.md)：合成有效购买的无期限缓存离线超过 9 天后可解码；独立测试离线 31 天后重建存储仍可读双轨。没有用真实课程或设备验证这两个期限。

真实 Flutter widget 流程覆盖缓存本章、管理列表、删除确认与取消、窄屏大字、切号期间旧内容消失。服务测试使用合成账号及授权响应，生产磁盘文件与回环 HTTP 检验续传；额外使用 FFmpeg 自建含画面及声音的 1 秒 MP4，在生产下载器下载、过期后发一次 HEAD 复核（媒体正文为 0 字节）、停止服务后打开并实际解码音画。双轨回环测试额外覆盖签名刷新、同长度损坏、旧票据、撤销、临时失败及换号/取消。另验证真实单视频轨 MP4 不得标记为音画完整；Windows 播放后端校验账号、文件与章节一致，换号即停止。另有 Flutter → Android 本地播放参数测试和 Android JVM 路径、时限用例。
