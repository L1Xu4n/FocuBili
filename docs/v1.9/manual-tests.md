## Android 升级与功能验收

- [ ] **覆盖升级与资料保留，非本 Beta 发布必需**：只在另行授权、实际包名及证书相同且构建号递增的测试环境验证合成清单、笔记、分 P 进度、专注、订阅及布局保留。证书不同的旧 Beta3/4/5 不执行覆盖，记录为不兼容而非发布阻塞；可在空白环境测试本 Beta。正式包与 preview 不自动迁移，不卸载旧应用、不清数据。
- [ ] **跨视频专注**：开始 1 分钟专注，在未打开视频时观察计时；打开视频，暂停、换 P、回搜索换另一视频。预期同一次会话连续累计，不因视频暂停/完播/换 P 产生新记录；时间到只归档一次。
- [ ] **暂停与后台**：手动暂停专注 10 秒，再切换视频。预期不会偷偷恢复。主动继续后进入后台或锁屏，返回前台；预期后台不累计，等待主动继续，同一会话的已累计时间保留。提前结束后重启 App，不应复活旧任务或重复归档。
- [ ] **学科文件夹**：新建“数学”，把两条旧任务移入，重命名，修改其中一条进度，再删除文件夹。预期任务回到未分组，原视频、分 P、进度和关联笔记都保留。重启后复查；再测试多选移动及新增任务时选择分组。
- [ ] **多画面笔记**：同一笔记插入 00:10、00:40、01:15 三个画面，调整顺序，删除中间一张并保存。预期重开后顺序和各自时间准确，笔记原锚点不被追加画面改变。至少分别测一次横屏和竖屏视频预览。
- [ ] **删除与异步保护**：编辑已有笔记后立即删除，等待两秒再重开，预期不会自动保存回来。追加画面时快速切换合集视频/分 P，预期不会把新视频跳到旧时间点，不会在新视频中写入旧截图。
- [ ] **笔记导出**：分别导出有多张画面的 Markdown/JSON，解压后打开，预期图片相对路径可用、顺序及毫秒时间点保留。取消系统保存应显示取消；存储不可写应显示失败诊断码，不显示成功。缺失旧截图时文字和缺图位置保留，并明确提示缺图数量。
- [ ] **字幕阅读**：使用已确认有可读取字幕的视频，打开列表、搜索一句字幕并点击。预期跳转对应时间点；搜索不生成新字幕。分别导出 SRT/TXT，检查中文、起止时间和完整轨道。无字幕、需登录、获取失败应显示真实状态并可重试。

- [ ] **稳定版与 Beta 通道分离，Android / Windows / macOS / Linux**：分别用没有 Beta defines 的稳定构建和带 Beta defines 的候选检查更新。预期稳定版保持原生版本显示及 latest 通道，不接受 prerelease/preview APK；Beta 使用有界 prerelease 列表，不回退稳定 latest 或稳定 APK。记录候选 source 和实际请求证据；旧 Beta4/5 自带的旧更新器不会被新代码追溯修复。
- [ ] **显示版本与原生计数一致，多平台**：核对候选的 Beta 显示版本、原生版本和 BuildTime/source。预期 desktop 原生版本仍为数字形式，Beta 显示是有效 SemVer；已有 `+local` 元数据和非空原生 counter 合并后只有一个 `+`，空 counter 保留合法元数据。当前预留 2026 不是新安装包已验证结果。
- [ ] **有界发现与错误，合成网络 / 各平台 UI**：放入分页候选、draft、稳定标签、较低 Beta、无更高版本及后页失败；再测离线和限流。预期最多 3 页×30 条，以 SemVer 选择更高 prerelease，说明 90 条边界；后页失败不返回先前的半截候选，错误可重试，忽略版本与手动检查行为保留。
- [ ] **未知包名与元数据回退，Android**：注入未知/读取失败的安装包名，或缺失、超大、损坏、跨 tag/source、重复 Android 资产、大小/hash/API URL 不符的 manifest。预期有效发现结果只打开该仓库对应 Release 页面，不选 APK，不偷偷回退稳定 APK；API/manifest 跳转只允许实现规定的 HTTPS 范围。
- [ ] **已知证书/计数冲突，Android**：用合成安装身份分别提供旧 `5BD1` 证书、与新包相同的 code、更高的已安装 code，再提供同证书且较低 code 的匹配身份。预期已知不兼容时回到 Release 页面；满足选择规则也只是下载选择，不是实际验签或 OS 覆盖升级通过。
- [ ] **证书或计数读取不全，Android**：用受控合成配置令已知 preview 包的证书缺失/非法，或原生 code 缺失/非法。预期全部回到对应 Release 页面；只有完整 64 位十六进制证书与候选一致、canonical 十进制非负原生 code 严格低于候选时才提供 APK 直链。真实 PackageInfo 结果另记设备/系统/构建，不把防御性坏 code 用例描述成真机故障；直链选择通过不代表 OS 覆盖升级或资料保留已验收。
- [ ] **候选 APK 身份与归档边界，Android**：新候选存在后只读核对实际包名、版本、code、单证书和有效签名、非 debuggable、实际 Flutter ABI、BuildTime/source、hash/大小及对应实际 CI。预期受控 release preview 身份和现有 CI `65EF` 证书，counter 2026 大于归档 2025 且大于届时 live inventory；不得以文件名或源码代替实包证据。无需与旧 `5BD1` Beta3/4/5 同证书或完成覆盖升级。
- [ ] **专用设备升级与合成资料，Android，非发布必需**：只有实际已安装 preview 的证书与候选相同、code 严格递增且双方身份已核验时，才在另行授权的测试设备测试合成资料保留。身份不兼容或未知时不执行这项覆盖测试，可改用空白环境验证功能，不因此阻断 Beta 发布。不卸载、清数据或替换签名，正式包与 preview 分离；历史公开 code21 或 manifest 选择不能自动勾选此项。
- [ ] **producer 候选与精确 source，CI 证据**：最终 source 确认、默认分支能力准备完成后，先检查 `publish=false` 候选 run。预期对应 source 的必要 push CI 和全部候选平台任务成功，平台记录和下载 bytes/hash/source 相同，七个二进制、manifest 与校验表完整；源码不同、部分成功或缺平台不能验收。此项尚无实际运行证据，不在本清单触发工作流。
- [ ] **Windows Beta 安装路径与文件操作**：在隔离系统账号核对 installer/portable 版本、source、运行时 DLL 和真实保存/取消；记录与稳定版共用 AppId/资料路径的影响。预期不能声称桌面 Beta 有独立数据沙箱，不用旧版写回 1.9 文件夹数据，不把导出当作完整回滚恢复。
- [ ] **macOS 候选架构与系统行为**：按对应 CI `macos-package-verification.json` 及实包核对真实架构、版本/source、ad-hoc 与正常应用字节一致性，再独立记录保存对话框、视频窗口和订阅生命周期。只有实际 lipo/CI 证据存在才标记架构；不凭 `macos.dmg` 文件名声称 universal、notarized 或真机通过。原 #61 未回复，不将这些补测写成 Mac 原问题已复现。
- [ ] **Linux Beta 包与桌面服务**：核对实际 control 版本 `1.9.0~beta.N+counter`、架构、包内 ELF 和依赖清单；再在目标系统测试窗口、媒体、通知及真实保存/取消。预期 Beta 的 Debian 版本早于同版本正式包；静态依赖声明或 CI 通过不替代目标桌面运行验收。
- [ ] **iOS 候选与生命周期**：区分 CI simulator 证据、unsigned IPA 和真机 provisioning；在后续授权环境另验前后台更新显示、通知/订阅回调及保存/分享。unsigned IPA 不描述为可直接安装或 TestFlight 已发布，模拟器通过也不能勾成真机通过。
