# Beta 3 之后：旧 issue 的逐项复查

这不是新版发布说明。基线是 [已发布的 v1.9.0-beta.3](https://github.com/L1Xu4n/FocuBili/releases/tag/v1.9.0-beta.3) 对应的 [dev e89b140](https://github.com/L1Xu4n/FocuBili/commit/e89b140a4cf672b8020c2abf41d5bdf7fda3c3d6)。从[原承诺表](beta3-acceptance.md)出发，优先关注旧功能现在是否可操作、出错后能否回来、会不会误写用户数据。每个专题 PR 附操作步骤和证据。未发布新版本，也未更改 Beta 3 标签或安装包；PR 的 CI 构建制品不是新发行。

## 做了什么

| 原反馈 | 复现的问题与本轮变化 | 验证方法和还不能证明的事 |
| --- | --- | --- |
| [#30 合集与多 P](https://github.com/L1Xu4n/FocuBili/issues/30) | 播放器合集卡的加号绕过分 P/分组选择；从选择流程返回时，退场动画期间仍会请求下一支。现在先明确选择和确认，取消不写入；同批含失效分 P 会整批拒绝，不再报错却写入一部分。 | 两页两支各五个分 P，一次加入十项；已有分 P 的进度保留，取消不继续请求。使用合成合集和详情，未操作真实账号的收藏。见[学习与专注][learn]。 |
| [#31 焦点订阅](https://github.com/L1Xu4n/FocuBili/issues/31) | 一个来源失败时，立即重试原先可能检查另一个刚成功的来源。现在让目标来源立即续查，不强制重查刚成功的其他来源。扫描期间标记已读，即使被显示缓存挤出，也不再误交给通知。 | 注入第 4 页失败并恢复，检查续查的页和来源；再加入 500 条触发缓存淘汰。未测系统托盘、锁屏投递或准点唤醒。[PR #105](https://github.com/L1Xu4n/FocuBili/pull/105) |

| [#58 已购课堂](https://github.com/L1Xu4n/FocuBili/issues/58) | 打开课程链接、切后台、换号再取消，旧页一直转圈。现在刷新当前账号，旧账号在途结果不能重新写回；购买列表跨页有重复项不再提前判定未买。 | 控件和服务模拟两账号及分页重叠。没有购买、没有绕过权限；[三星平板真实已购验收](https://github.com/L1Xu4n/FocuBili/issues/58#issuecomment-6251138527)是已有 Beta 1 记录，不是本次实测。[PR #103](https://github.com/L1Xu4n/FocuBili/pull/103) |
| [#60 搜索、分区和筛选](https://github.com/L1Xu4n/FocuBili/issues/60) | 已有搜索结果时断网，改本机排除词原先会重查第 1 页并丢掉结果。现在复用已加载条目；更改远端条件（分区、排序、日期或时长）则重新请求。首次读规则失败不会用默认值覆盖原排除词。 | 在真实页面筛选、清空，并查请求计数与存储原值。没有将关键词升级为 AI 分类，也未添加首页使用指南；未缓存的新页仍可能需要网络。[PR #106][filters] |

## 哪些刻意没再改

- **[#50](https://github.com/L1Xu4n/FocuBili/issues/50)、[#89](https://github.com/L1Xu4n/FocuBili/issues/89)：** 保留 Beta 3 已重写的抽屉、空布局搜索、收藏/关注卡片。这轮不再改手势或重复做卡片。此前的三版对比及卡片证据详见[原验收表](beta3-acceptance.md)；真机手感、帧率及真实账号分组导入仍欠实测。
- **[#82 Linux DEB](https://github.com/L1Xu4n/FocuBili/issues/82)：** 仍按实际 ELF 依赖打包，不硬编码库名。本地三种错误包反例与四个结果解析测试通过。三个正常打包用例因测试容器缺系统包元数据而未能完成；不要把历史上 Ubuntu 24.04 的运行或 26.04 的依赖解析写成本轮跨版本原生安装。
- **[#87 夜间图标](https://github.com/L1Xu4n/FocuBili/issues/87)：** 复核资源引用与五种密度 PNG 的实体像素。标志主体位于安全区，深色底上标志像素的中位对比度约 4.98:1。无证据应再画一套；未验证 ColorOS 15 桌面渲染。
- **[#97 笔记](https://github.com/L1Xu4n/FocuBili/issues/97)、[#98 自动字幕](https://github.com/L1Xu4n/FocuBili/issues/98)：** 保留 Beta 3 笔记 Markdown/原图保存和三种自动字幕优先级，本轮只动已有字幕的列表浏览，不增加轨道、不生成字幕。
- **范围外：** [#59](https://github.com/L1Xu4n/FocuBili/issues/59) 的自行生成字幕/评论区，以及 Beta 2 明确排除的 [#78](https://github.com/L1Xu4n/FocuBili/issues/78)、[#79](https://github.com/L1Xu4n/FocuBili/issues/79)，不在本次完成项内。新反馈 #93–#96 不挪作旧项成果，例如没有新增 #95 要求的倒序学习模式。

## 验收口径

使用锁定依赖、Linux Flutter 3.44.6 的真实控件、合成账号/媒体、可控时钟和本机存储替身；每项都标注了未复验的设备或网络。有独立审查先在旧实现跑出失败，再在候选复跑。不同专题与独立测试有重合，不能相加当成全项目总数。本轮没有做整机性能跑分；本文涉及性能的结论仅限实际检查的请求次数、持久化写入时机、分页取消与采样边界。

本地将 7 个代码 PR 的实际远端分支按 #103→#109 顺序合并演练，无冲突，合并得到的 `lib/` 和 `test/` 与终验完全一致。最终全项目 Flutter 测试 **1769 通过、2 跳过、0 失败**；静态分析无问题，531 个 Dart 文件格式未变，发布工具另有 43 项通过。这不是远端所有工作流成功的证明；各工作流状态以对应 PR 的 Checks 为准。
