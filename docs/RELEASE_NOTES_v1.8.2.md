## Android 播放

播放或暂停回调只有在 Media3 实际处于 READY 时才恢复就绪状态。新请求会撤销旧请求、移除等待中的过期任务，并关闭旧请求拥有的连接；已经返回但尚未提交到主线程的旧结果也会被丢弃。

本次保持原有清晰度、codec、缓存、CDN 候选顺序、网络超时和 LoadControl 策略。尚未在反馈的 HUAWEI BAH3-W59 上验证，不能据此宣布该设备的所有卡顿已解决。

## 诊断与隐私

媒体运行记录仅在当前进程内存保存，最多 64 条，复制问题诊断时附带；清空诊断可同时清除这些记录。首帧与解码器摘要会在播放器关闭后保留，应用进程重启后消失，请在重启前复制。

记录使用固定字段和枚举，不记录 Cookie、完整或签名 URL、请求头、响应正文、字幕正文、视频标题或文件路径。周期采样只更新内存中的计数，不新增逐心跳诊断落盘。

## 验证范围

本次基于正式版 v1.8.1 的稳定线开发，没有合入 dev 的 1.9 功能。自动化结果、安装包限制和最少真机验证步骤见 [验证说明](reviews/v182-media3/README.md)。本说明是待发布内容，本地提交和测试安装包不构成正式发布。

## 搜索播放与详情会话

- 搜索结果优先使用已有真实 CID；缺少时解析分 P，完整详情在播放器中异步加载。详情失败不再阻挡已有 CID 的播放入口。
- 完整详情使用当前会话与 WBI 签名，独立于播放签名实验开关。移除纯角标自动详情请求，并按会话代次共享并发查询。
- 新增脱敏资料请求诊断，区分 HTTP 412 与业务码 -412，保留登录/注销旧结果隔离和账号只读语义。没有自动轮换账号、端点或反复重试；仍需 Apple 真机验证。
