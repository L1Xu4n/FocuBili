# FocuBili v1.0.1 发布说明

发布日期：2026 年 8 月 1 日

Android 最低版本：Android 7.0（API 24）

应用版本：`1.0.1+7`

## 本次重点

v1.0.1 重点完善“主动学习一支视频”的完整流程，并补齐互动视频、视频分段和播放器完播体验。

### 学习清单

- 搜索结果、视频详情和合集条目可以加入学习清单。
- 首页只突出一条“继续学习”任务，完整清单支持“未开始 / 学习中 / 已完成”。
- 首次加入时继承本机已有的分P和观看进度，播放过程中继续更新。
- 视频结束后由用户选择“标记完成”或“播放下一节”，不会自动连播。

### 搜索与内容页

- 重构搜索顶部、候选词、可换行搜索历史和扁平视频结果布局。
- 保留视频 / 用户搜索切换、排序与筛选；清空全部历史前会再次确认。
- 搜索结果的学习清单操作移入三点菜单，重复点击可以确认取消加入。
- 修复简介中结构化 `@UP` 的颜色、`@` 字符、真实 MID 和主页跳转。
- 压缩 UP 主页资料区域，减少短简介造成的大块空白。

### 播放器

- 接入互动视频剧情节点和分支选择；只有用户点击卡片后才打开目标剧情。
- 分支卡片改为无色黑灰半透明样式，播放栏出现时自动上浮。
- 支持视频分段进度条、章节跳转、章节预览图和分段信息面板。
- 分段进度条在竖屏和全屏都位于视频画面内，隐藏播放栏时可以铺满画面宽度。
- 完播提示改为紧凑布局，修复 720 × 360 横屏下的底部溢出和播放栏遮挡。
- 修复 Android 原生播放层错误限制三倍速的问题，长按临时三倍速恢复可用。
- 修复互动视频接近结尾时没有弹出选项，以及完播状态被暂停回调覆盖的问题。

### 时间点笔记

- 点击笔记只切换编辑内容，不再自动跳到记录时间。
- 增加明确的“跳转到时间点”按钮。
- 标题或正文停止输入后自动保存，关闭页面前会补存等待中的草稿。

## 隐私说明

- 学习清单、观看进度、搜索历史和时间点笔记只保存在当前设备。
- 项目没有自建服务器，不会把 B 站 Cookie、本机记录或笔记上传给开发者。
- 互动视频和视频分段只读取播放所需的公开数据，不绕过付费、会员、隐私或地区限制。
