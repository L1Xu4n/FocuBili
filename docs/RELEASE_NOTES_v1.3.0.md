- 切换后立即重建全应用主题，系统栏图标颜色同步变化；退出和重启 App 后继续使用上次选择。
- 主题偏好只保存在设备本地，不会上传账号、服务器或第三方平台。

## 平板横屏与后续 Windows 基础

- Android 平板在原生 Activity 创建 Flutter 页面前请求横屏；手机继续保持竖屏，系统不允许锁定时按实际窗口自适应。
- `900dp` 以上横向窗口使用左侧一级导航，并让首页、搜索、“我的”、专注数据和主要二级页面使用专门的双栏或双列布局。
- 收藏夹及内容、订阅及合集详情、观看记录、关注、笔记和 UP 主页按可用宽度增加信息密度，窄窗口仍回退单列。
- 布局判断基于 Flutter 窗口尺寸而不是 Android 设备名称，便于后续 Windows 端复用。

## 播放器

- 平板横屏默认显示视频与详情/学习/笔记/分P侧栏，不再把常驻横屏误判成手机沉浸全屏。
- 平板非全屏也可在画面左半区上下滑动调亮度、右半区上下滑动调音量；顶部展示专注信息、本地时间、网络类型和电量。
- Wi-Fi 与移动网络可以分别选择默认清晰度；目标档位不可用时只向更低档回退，避免移动网络意外升档。
- 弹幕按播放器完整宽度从右边缘进入并向左穿屏；迟到片段、恢复历史和重新开启不再从画面中间补画旧弹幕。
- 播放器支持多层“视频 A → UP 主页 → 视频 B”返回恢复；重新显示 A 时恢复原分P、进度和播放状态。
- MuMu x86 模拟器使用更稳定的同步 MediaCodec 回调，ARM 真机继续使用 Media3 默认异步路径。
- 横屏播放页隐藏 Android 顶部状态栏，离开播放器后恢复；UP 主页投稿按钮补充“加入学习清单”。

## 笔记、链接与播放恢复

- 时间点笔记摘要和编辑信息栏显示来源 `P序号`；保存与删除后列表、选中项和详情状态同步。
- 支持从 QQ、浏览器或 B站网页通过 `bilibili://video` 和标准视频网址打开公开视频，兼容 AV/BV、分P和时间点。
- Media3 遇到容器解析损坏时仅清理当前分P缓存并绕过缓存重试，备用视频和音频线路使用完整交叉组合。
- 不增加绕过会员、充电、课程、地区、隐私或其他访问控制的逻辑。
