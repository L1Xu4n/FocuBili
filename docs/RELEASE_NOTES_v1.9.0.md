# FocuBili v1.9.0

从 v1.8.1 升级后，桌面首页、播放器和学习资料整理有较多变化；手机保留原来的首页下沿抽屉。

<!-- focubili-update-summary:start -->
- 学习清单支持按学科管理、批量加入分 P 和手动排序。选集时会显示实际会新增多少项，已有任务不重复计算。
- 普通视频可按分 P 批量离线缓存；离线列表按视频归拢分集，可在组内按 P 号或标题搜索、多选或删除。选定画质不可用时，会提示哪些分 P 改用了较低画质。已完成的下载任务记录保留 14 天，到期清理不删除缓存文件。
- 桌面和大屏横屏平板共用新版首页学习抽屉。启用后，桌面左栏的焦点订阅入口不会随页面切换消失。
- 移动鼠标即可唤出桌面播放控件；播放时鼠标不在控件上且静止 3 秒，控件自动收起。双击左右侧按已设区域快退或快进，双击中间切换全屏。
- B 站账号收藏夹会标出私密状态；关闭账号只读保护后，可修改自己创建的收藏夹名称和公开状态；默认收藏夹只能修改公开状态，原有简介与封面保留。「关于」新增支持视频入口。
<!-- focubili-update-summary:end -->

## 观看与整理

- 支持分 P、合集、收藏夹和学习清单的连续播放，以及 A–B 区间循环。可预设是否默认开启字幕及优先轨道，也可搜索、定位、导出已有字幕和调节外观。播放线路可设为备用线路优先。
- 时间点笔记支持多张截图、Markdown 预览和分享；可单独保存原图。专注计时不会因切换视频或分 P 自动结束。
- 软件收藏夹与 B 站账号收藏分开管理。本机收藏可排序、导入和备份。焦点订阅集中显示手动订阅的 UP 主和合集更新，不引入推荐流。
