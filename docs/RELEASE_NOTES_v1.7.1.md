# FocuBili v1.7.1

本次主要修复 Android 部分高清画质切换问题，并增加针对单次更新的红点忽略操作。

<!-- focubili-update-summary:start -->
- 修复部分情况下无法切换到更高清晰度的问题
- 改善播放会话、设备解码回退及安全诊断
- 关于页新增“忽略本次更新”，保留下载入口，主动检查可恢复提醒
<!-- focubili-update-summary:end -->

## 修复

- 修复部分情况下登录会话与播放请求不一致、影响高清画质获取的问题；避免混用不同域的账号信息，账号切换后丢弃旧请求。
- 修复轨道选择可能使用低清视频却显示较高清晰度的问题；先检查设备支持的编码，再选择允许范围内的画质，并在解码失败时有限回退。
- 登录会话暂时无法读取时，允许用户明确选择仅以游客播放当前视频；不会自动降为游客。
- 改善画质失败提示，增加不含 Cookie、账号标识或媒体地址的请求诊断，便于判断会话、服务端返回和设备解码限制。

Windows、macOS、Linux、iOS 的播放鉴权和轨道选择未在本补丁中调整；共用画质提示和诊断界面随版本更新。此修复不保证获得账号、视频或设备本身不支持的画质。

本次不包含 1.8 测试分支的订阅、卡片或缓存功能。

## 忽略本次更新

设置 → 关于 → 更新区域新增“忽略本次更新”。只忽略当前已经检测到的具体版本和发布通道，主界面与设置入口不再显示该版本红点；更新页仍保留版本、说明与下载入口。此选择保存在本机，自动检查同一版本不会取消；新的版本正常提示。主动点击“重新检查”立即取消忽略，即使本次网络检查失败也不恢复忽略，已检测到的下载信息仍保留。

## 安装与升级

正式资产仅在构建、审查、版本及签名验证完成后附加。Android 保持原包名与既有发布证书，覆盖安装前需核对实际产物；不要先卸载旧版或清除数据。

现有 iOS 工作流仅生成需要自行签名的开发归档，不具备已验证的正式签名分发能力，不将其列为可直接安装的正式 IPA。macOS 沿用现有 ad-hoc 签名、未公证方式，系统可能限制首次打开。
