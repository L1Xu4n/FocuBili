# FocuBili v1.2.0 发布说明

发布日期：2026 年 8 月 7 日

Android 最低版本：Android 7.0（API 24）

应用版本：`1.2.0+11`

## 本次重点

v1.2.0 主要改善 Android 平板、横屏和分屏窗口中的阅读宽度，并修复一级页面返回、隐藏输入焦点、平板网页登录和视频详情 HTTP 412。

### 平板布局

- `600dp` 起增加平板页边距，`840dp` 起使用宽屏留白。
- 首页专注卡片最大宽度为 `840dp`，搜索主体为 `960dp`，“我的”主体为 `720dp`。
- 搜索的视频/用户模式选择器最大宽度为 `480dp`，不再横跨整个平板屏幕。
- 1024×600 等矮横屏或分屏窗口会缩短首页欢迎区，保留首张卡片的可达性。

### 登录与公开视频请求

- 官方网页登录改用 `passport.bilibili.com` 的 H5 登录入口。
- 登录 WebView 读取设备真实 UA；平板 UA 缺少 `Mobile` 时只补充该标记，不伪造账号资料。
- 视频详情和标签请求使用对应 BV 的精确视频页 Referer，修复旧桌面 UA 配根域来源时出现的 HTTP 412。
- 公开详情请求继续不发送 Cookie，不在 412 后轮换代理、请求身份或快速重试。

### 返回与输入焦点

- 切换首页、搜索和“我的”前释放当前输入焦点，隐藏页面也不能重新抢占焦点。
- 从设置页返回后不会自动唤起输入法，键盘输入不会再写入隐藏搜索框。
- 搜索页和“我的”页的系统返回先回首页；首页系统返回仍可正常退出 App。

## 验证

- `flutter analyze --no-pub`：0 个问题。
- `flutter test --no-pub`：256 项全部通过。
- `git diff --check`：通过。
- 平板布局专项测试覆盖 599×400、1024×600 与 1280×800 的内容宽度、断点和首页高度。
- 请求策略专项测试覆盖 H5 登录地址、移动 UA、精确视频来源和无 Cookie 请求头。
- 主框架专项测试覆盖一级子页系统返回、首页允许退出和隐藏搜索焦点回归。
- Debug APK 已覆盖安装到 Android 15、约 600dp 宽的平板模拟器，包版本确认为 `1.2.0+11`。
- 模拟器使用公开 BV 搜索并进入播放器成功，视频详情不再返回 HTTP 412；搜索页系统返回先回首页，设置页返回未唤起输入法。
